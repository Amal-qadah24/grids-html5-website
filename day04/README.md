
## Day 04 – Flexbox, Grid & Responsive Design

### Overview

Day 04 focuses on building responsive layouts using CSS Flexbox,
CSS Grid, and mobile-first design principles.

### Learning Objectives

- Build responsive navigation using Flexbox.
- Create responsive card layouts using CSS Grid.
- Understand normal document flow and positioning.
- Apply media queries for different screen sizes.
- Identify and fix horizontal overflow issues.

### Required Work

1. Responsive Navbar.
2. Responsive Card Grid.
3. Challenge C08 – Responsive Repair.
4. Test layouts on mobile, tablet, and desktop.

### CSS Features

- display: flex
- flex-direction
- justify-content
- align-items
- flex-wrap
- display: grid
- grid-template-columns
- repeat()
- minmax()
- auto-fit
- Media Queries
- Overflow handling
- Focus-visible states

### Deliverables

- Responsive navigation.
- Responsive card grid.
- Fixed horizontal overflow.
- Mobile, tablet, and desktop screenshots.
- Explanation of Flexbox vs Grid.

### Exit Ticket

1. What did I build today?

   Improved the website with responsive navigation and a CSS Grid card layout.

2. What bug or difficulty did I solve?

   Identified and fixed potential horizontal overflow issues.

3. What concept can I explain clearly?

   Flexbox, CSS Grid, and mobile-first responsive design.

4. What remains incomplete?

   Final responsive testing and cross-browser review.
