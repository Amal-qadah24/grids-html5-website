
# Day 02 - CSS Foundations & Responsive Design

Grids Apps Full Stack Web Development Internship (Foundation Track).

## Pages
- `index.html`: styled semantic homepage with a dark theme.
- `profile.html`: styled Profile & Biography page.
- `style.css`: shared stylesheet for both pages.

## Structure
```text
day02/
  index.html
  profile.html
  style.css
  README.md
  assets/
    images/
      img.jpg
      profile.svg
```

## Technologies
HTML5, CSS3.

## CSS Features
- CSS Variables for color management.
- Dark theme using custom color palette.
- Typography, spacing, borders and hover effects.
- Flexbox for navigation layout.
- Responsive design using media queries.
- Shared stylesheet across multiple pages.

## How to run
Open `index.html` in a browser (or use the VS Code Live Server extension).
